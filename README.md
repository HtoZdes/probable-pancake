# ВОЛС инжиниринг — сайт-визитка

Статичный сайт из трёх страниц: `index.html` (главная и контакты), `services.html` (услуги), `projects.html` (объекты, 28 шт. с фильтром).
Без сборки и зависимостей: откройте `index.html` в браузере или выложите папку на любой хостинг (например, GitHub Pages).

## Что нужно заполнить
Контакты-заглушки (поиск по проекту и замена во всех трёх HTML-файлах):
- телефон: `+7 (000) 000-00-00` и `+70000000000`
- e-mail: `info@example.ru`

## Структура
- `assets/css/style.css` — стили; цвета заданы переменными в `:root` (синий основной, серебро → белый вторичный)
- `assets/js/main.js` — мобильное меню и фильтр объектов
- `assets/img/` — логотип-знак и favicon (временные, заменить на фирменный логотип)
